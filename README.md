# GrooveVPN Bot

Telegram-бот для продажи VPN-доступа пакетами трафика. Работает поверх панели
[Marzban](https://github.com/Gozargah/Marzban): сам создаёт и продлевает профили,
выдаёт ссылку подписки, ведёт заказы, пробные периоды, рефералов и бонусный баланс.

Python 3.12 · python-telegram-bot (async) · SQLAlchemy 2.0 + SQLite · httpx · loguru · uv · pytest · Docker

Бот работает в продакшене; в репозитории нет секретов и пользовательских данных.

## Возможности

- **Покупка и продление.** Выбор тарифа, оплата переводом + фото чека, заявка администратору
  с кнопками «Подтвердить / Отклонить». После подтверждения профиль в Marzban создаётся
  (или продлевается, трафик суммируется) автоматически, клиент получает ссылку подписки.
- **Идемпотентность.** Повторное подтверждение, повторный клик и сбой Marzban не приводят
  к двойной выдаче или потере оплаты (тесты `test_new_purchase_idempotency`, `test_order_consistency`).
- **Пробный период.** Лимит трафика и срока, суточный лимит выдачи, фоновая проверка
  и уведомления; состояние и флаги уведомлений хранятся в БД.
- **Рефералы и бонусный баланс.** Одноразовые ссылки, бонус другу, процент пригласившему,
  месячный лимит наград, журнал баланса, резервирование при оформлении заказа,
  оплата балансом без участия администратора.
- **Подключение в один тап.** Статичная страница-прослойка (`web/connect`) открывает
  Happ / v2RayTun / Hiddify; данные в URL-фрагменте не попадают в логи сервера, ввод
  валидируется по белым спискам.
- **Перенос остатка трафика**, таймауты и ретраи клиента Marzban.

## Архитектура

Clean Architecture с зависимостями внутрь, DI вручную в `src/main.py`:

```
src/
  domain/       сущности и чистые правила (тарифы, триал, рефералы, перенос трафика)
  use_cases/    сценарии: заказ, админ, триал, рефералы, проверка трафика
  adapters/
    db/         репозитории SQLAlchemy, атомарное проведение оплат
    marzban/    HTTP-клиент панели (контракт: docs/marzban_openapi.json)
    tg_bot/     хендлеры Telegram, уведомления
```

Принципы проекта записаны в [конституции](.specify/memory/constitution.md); каждая
крупная функция сначала описана спецификацией (`specs/001…004`: MVP, триал, ссылки
подключения, рефералка) — разработка по spec-driven подходу.

## Запуск

```bash
cp .env.example .env     # заполнить токен бота, id админа и доступ к Marzban
uv sync
uv run python -m src.main
```

или `docker compose up -d --build` (база лежит в `./data`).

Переменные окружения описаны в `.env.example`. Обязательны `TELEGRAM_BOT_TOKEN`,
`TELEGRAM_ADMIN_ID`, `MARZBAN_API_URL`, `MARZBAN_USERNAME`, `MARZBAN_PASSWORD`.

## Тесты

```bash
uv run pytest
```

Около 25 модулей: заказы и идемпотентность, баланс/журнал, рефералы (правила, привязка,
награды, UI), триал, таймауты Marzban, ссылки подключения. Базы — временные файловые
SQLite, внешние сервисы подменены фейками (`tests/fakes.py`). Для страницы подключения:
`node --test web/connect/validate.test.mjs`.

## Безопасность

- Секреты только в `.env` (в `.gitignore`), база `data/` не в репозитории.
- Страница подключения: CSP `default-src 'none'`, `no-referrer`, белые списки приложений и хостов.
