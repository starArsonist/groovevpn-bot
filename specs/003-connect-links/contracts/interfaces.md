# Контракты: connect-links

## 1. URL страницы-прослойки (бот -> страница)

```text
https://<CONNECT_PAGE_URL>#app=<app>&sub=<percent-encoded URL подписки>
```

- `app` in `happ | v2raytun | hiddify`.
- `sub` - полный URL подписки, закодированный `urllib.parse.quote(sub_url, safe="")`.
- Данные во фрагменте: не отправляются на сервер и не попадают в его логи. Адрес страницы из конфигурации не должен содержать фрагмент (при наличии - отбрасывается).
- Страница не принимает данных в query-параметрах.

## 2. Deeplink приложений (страница -> приложение)

| app | Шаблон | Статус источника |
|-----|--------|------------------|
| `happ` | `happ://add/<sub>` | со слов владельца; в официальных страницах Happ синтаксис не найден |
| `v2raytun` | `v2raytun://import/<sub>` | со слов владельца; официальной документации не найдено |
| `hiddify` | `hiddify://import/<sub>#<encodeURIComponent(PROFILE_NAME)>` | подтверждено: <https://hiddify.com/app/URL-Scheme/> |

`<sub>` - нормализованный URL (`URL.href`) после валидации.

## 3. Валидация на странице

```text
validate(params, allowedHosts) -> { ok: true, app, sub } | { ok: false }
```

- `app`: собственный ключ таблицы `APPS`.
- `sub`: строка <= 2048 символов, без пробелов и управляющих символов; https; без учётных данных и фрагмента; `hostname` (нижний регистр) точно входит в `allowedHosts`; пустой список = отказ.
- `{ ok: false }` -> нейтральное сообщение, редиректа нет.

## 4. Конфигурация бота

| Переменная | По умолчанию | Правила |
|------------|--------------|---------|
| `CONNECT_PAGE_URL` | пусто | https, хост с точкой, без учётных данных и пробелов; иначе кнопки выключены + предупреждение |
| `CONNECT_APPS` | `happ,v2raytun,hiddify` | порядок = порядок кнопок; неизвестные пропускаются с предупреждением |

## 5. Telegram UI

Строки кнопок (в порядке сверху вниз): кнопки приложений (по одной в строке, «Подключить в Happ» и т.п., `url=` страница) -> существующие действия сообщения -> «Поддержка».

| Сообщение | Кнопки приложений |
|-----------|-------------------|
| Выдача триала (GRANTED), повторный показ ссылки активного триала (ALREADY_ACTIVE) | да |
| Первая оплаченная покупка (новый пользователь, включая fallback 404) | да |
| Экран «Моя подписка» | да |
| Продление существующей подписки (в т.ч. покупка триал-пользователем) | нет |

Тексты (с кнопками): «Нажмите кнопку своего приложения - подписка добавится автоматически. Если приложение не открылось, скопируйте ссылку и добавьте её вручную.» Без кнопок - прежние тексты.
