# Quickstart: connect-links

## Конфигурация бота

```env
CONNECT_PAGE_URL=https://connect.example.com/
CONNECT_APPS=happ,v2raytun,hiddify
```

Пусто или невалидно (не https, хост без точки) - кнопки не показываются, бот работает как раньше, в логе предупреждение.

## Страница

Файл `web/connect/index.html` - статика. Перед деплоем пропишите хост подписки в `ALLOWED_SUB_HOSTS` в начале файла (по умолчанию пусто = страница всем отказывает). Подробности - `web/connect/README.md`.

## Тесты

```bash
uv run pytest -q
node --test web/connect/validate.test.mjs
```

## Проверка вручную (после деплоя страницы, на устройствах)

1. Выдать триал -> под ссылкой кнопки приложений.
2. Нажать кнопку -> страница -> приложение открывается и добавляет подписку (iOS, Android, Windows, macOS).
3. Проверить поведение внутри встроенного браузера Telegram (подсказка «открыть в браузере»).
