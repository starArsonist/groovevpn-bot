# Quickstart: free-trial

## Конфигурация

Добавьте в `.env` (не обязательно - есть значения по умолчанию; `.env.example` будет обновлён):

```env
TRIAL_ENABLED=true
TRIAL_DATA_GB=10
TRIAL_DAYS=7
TRIAL_DAILY_CAP=50
```

`TRIAL_ENABLED=false` скрывает кнопку и блокирует выдачу новых триалов (уведомления по уже выданным продолжают работать).

## Локальный запуск тестов

```bash
uv run pytest -q
```

Тесты используют временную файловую SQLite и фейковые Marzban/Telegram - реальная панель и токены не нужны.

## Развёртывание

Новая таблица `trials` создаётся автоматически при старте бота (`create_all`). Ручных миграций существующих таблиц нет. Опциональный DDL - в `data-model.md`.

## Проверка вручную (на тестовом боте, после реализации)

1. `/start` у нового пользователя -> первая кнопка «Попробовать бесплатно».
2. Нажать -> получить ссылку; повторное нажатие - «уже выдан».
3. Купить пакет -> после подтверждения администратором лимит равен размеру пакета, срок 30 дней.
