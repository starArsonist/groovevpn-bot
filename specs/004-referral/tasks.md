## Решения владельца по вопросам плана (2026-10-08)

1. Резерв при создании заказа, возврат при отклонении; **пользователь может отменить свой неоплаченный заказ** (кнопка «Отменить заказ») - освобождает резерв; отмена/подтверждение/отклонение - взаимоисключающие условные переходы под одним lock. 2. Автоистечения нет. 3. Правки пути новой покупки: при 409 профиль переиспользуется только если имя соответствует схеме `user_<telegram_id>_<order_id>` этого пользователя; тест на чужой профиль. 4. «Действует, пока не использована». 5. Частичное списание автоматически, полное - по кнопке «Оплатить балансом»; при сбое Marzban резерв остаётся, повтор идемпотентен, аварийная карточка админу. **Оплата балансом только при цене > 0 и балансе >= цены; заказ без реальной цены не подтверждается.** 6. Число ГБ в текстах - из `REFERRAL_INVITEE_BONUS_GB`. 7. Месяц по UTC. 8. Привязки закрываются лениво - при первой покупке приглашённого. 9. `/balance <id>` - только просмотр. 10. При расхождении `BOT_USERNAME` и `get_me` - warning в лог. 11. Тест «просроченная» заменён.
