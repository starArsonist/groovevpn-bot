# Quickstart: referral

## Настройка

Добавьте в `.env` (значения по умолчанию указаны; все ключи необязательны):

```
REFERRAL_ENABLED=true
REFERRAL_INVITEE_BONUS_GB=15
REFERRAL_REWARD_PERCENT=30
REFERRAL_MAX_ACTIVE_LINKS=3
REFERRAL_MONTHLY_CAP=10
BOT_USERNAME=
```

`BOT_USERNAME` (без `@`) можно не задавать: имя берётся из `get_me` и кэшируется. Если задано и отличается от `get_me`, в лог пишется предупреждение, используется значение из `.env`.

`REFERRAL_ENABLED=false` отключает создание ссылок, привязку и новые бонусы/награды (кнопка «Пригласить друга» скрыта). Баланс остаётся видимым и тратимым.

## Боевая БД

1. Скопировать `data/bot.sqlite3`.
2. Новые таблицы (`referral_links`, `referrals`, `balance_entries`, `order_payments`) бот создаёт сам при старте. Либо применить заранее `specs/004-referral/migration.sql` (идемпотентный, существующие таблицы не затрагивает).
3. Существующие таблицы не меняются; ожидающие заказы, созданные до релиза, обрабатываются как оплаченные деньгами целиком.

## Как это работает для пользователя

- «Пригласить друга»: до 3 одноразовых бессрочных ссылок, «Новая ссылка», «Отозвать ссылку».
- Друг открывает `https://t.me/<бот>?start=ref_<токен>`; если он без подтверждённых платных заказов, привязка срабатывает один раз навсегда.
- При первой покупке друг получает +`REFERRAL_INVITEE_BONUS_GB` ГБ к пакету, пригласивший - `REFERRAL_REWARD_PERCENT`% от денежной части (вниз до рубля) на баланс.
- Баланс при покупке списывается автоматически и резервируется при создании заказа. Экран оплаты показывает «Списывается с баланса» и «К оплате». Если баланс покрывает цену - кнопка «Оплатить балансом» (без чека и без шага администратора).
- Неоплаченный заказ можно отменить кнопкой «Отменить заказ» (пока выдача не началась): резерв возвращается. Отклонение администратором возвращает резерв так же.

## Для администратора

`/balance <telegram_id>` - просмотр: баланс, резервы под ожидающие заказы, последние 10 записей журнала. Корректировки баланса нет.
Если оплата балансом не смогла выдать пакет (сбой Marzban), приходит текстовая карточка «Оплата балансом: выдача не удалась» с кнопками «Подтвердить/Отклонить»; повторное подтверждение идемпотентно.

## Локальная проверка

```powershell
uv run pytest
```

Живой Telegram и боевой Marzban не используются: тесты работают на файловой SQLite и фейковом Marzban.
